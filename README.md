# Project Management Tools Workflow (Sample Project)

A sample project coordination workflow built with **ClickUp, monday.com, Asana and Trello**. It shows how I plan work, assign tasks, track progress and keep a team on schedule.

> This is a practice project with made-up tasks, built to show my process.

## Sample project
**Launching a new product page for a small online business** (4 weeks, team of 4).

## My coordination workflow
1. **Plan:** break the project into phases and tasks.
2. **Assign:** give every task an owner, a due date and a priority.
3. **Track:** update statuses (To do, In progress, Review, Done).
4. **Communicate:** post weekly progress updates and flag blockers early.
5. **Review:** check completed work and close the project with a short summary.

## Tools and how I use each one

| Tool | Best used for | What I set up |
|---|---|---|
| **ClickUp** | All-in-one task and doc management | Task lists, subtasks, due dates, priorities, time tracking |
| **monday.com** | Visual team dashboards | Project boards with status columns, timelines and owners |
| **Asana** | Task assignment and deadlines | Projects, milestones, dependencies, recurring tasks |
| **Trello** | Simple Kanban workflows | Boards with To do, In progress and Done lists, checklists, labels |
